# Steam Game Recommender (SGR)

### Tech stack:
1. Python backend (**FastAPI**),
2. React.js frontend (**Node.js, craco**),
3. **Docker** Containerization.


### How to run
1. Install **[Docker](https://www.docker.com/get-started/)** if you do not have it already,
2. Open terminal in project root and run command: 
```bash
docker compose up --build
```
3. If not opened, go to "localhost:3000/" on your internet browser,
4. Try out our recommendation system.
